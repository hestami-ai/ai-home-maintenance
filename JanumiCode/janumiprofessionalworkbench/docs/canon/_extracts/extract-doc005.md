- "Legacy phase completion | Compatibility milestone, not semantic satisfaction" (RPH-DOC-005.md L944) — Mapping-table rule: finishing a phase carries zero satisfaction authority in the canonical model.
- "REVIEW is governance, not merely another legacy work phase." (RPH-DOC-005.md L586) — Reclassifies human review out of the work pipeline into the governance plane, producing Decision Objects.
- "Store independent execution, assurance, and shape-integrity states." (RPH-DOC-005.md L1019) — Gap 6 remediation; the exec≠assurance separation extended to a third shape-integrity axis.

## DOCTRINE-CONOP

(RPH-DOC-005.md L27-34) — Six-way triage doctrine for every legacy behavior; only the last category is discardable.
- "Every finding is assigned one of three confidence levels." [Confirmed / Strongly inferred / Discovery required] ... "The Stage 0 implementation must replace inferred descriptions with code-grounded contracts before migration." (RPH-DOC-005.md L48-71) — Source-confidence doctrine: this document is self-declared non-authoritative until code-grounded.
- "These labels currently combine several different semantic categories: interaction mode; professional activity; execution state; governance state; control operation. That conflation is one of the principal migration targets." (RPH-DOC-005.md L117-125) — The INTAKE-substate diagnosis; five categories one enum conflated, driving the whole reclassification.
- "INTAKE is not one PWU Type. It is a legacy compatibility container whose professional content maps to multiple PWU Types plus interaction and control activities." (RPH-DOC-005.md L218-221) — One-legacy-phase-to-many-objects mapping rule; container phases decompose, never map 1:1.
- "| INTAKE | Shape Engineering | ... | REVIEW | Governance | | EXECUTE | Loop and Harness Engineering | ... | REPLAN | Loop control and reshaping |" (RPH-DOC-005.md L159-173) — Dominant-concern reclassification of all eleven phases; "the legacy phase abstraction hides several underlying objects and operations" (L173).
- "`REPLAN` is not a canonical work unit or terminal structure. It is a legacy phase label for a control response" (RPH-DOC-005.md L155) — REPLAN demoted to a family of controller Control Actions (revise/retry/reshape/escalate, L803-817) available anywhere.
- "This legacy behavior is not best represented as a global sequential legacy phase ... It is a cross-cutting assurance capability" (RPH-DOC-005.md L402-404) — ASSUMPTION_SURFACING becomes policy + extraction step + typed objects, not a pipeline stage.
- "the **Assurance Assessment** defines what must be established; the **verification PWU** performs substantive work needed to gather evidence." (RPH-DOC-005.md L508-511) — Division of labor when verification is itself substantial work.
- "This plan should be represented as a compatibility strategy for temporal execution, not embedded into the PWA's PWU Type hierarchy or an Undertaking's Professional Work Graph." (RPH-DOC-005.md L890) — The sequential legacy order survives only as an Execution Plan, never as composition structure.

- "It should not preserve accidental coupling such as: legacy phase names as database authority; pass/fail as the only assurance state; untyped carried context; a dedicated REPLAN endpoint in the semantic model; automatic equivalence between validation completion and acceptance." (RPH-DOC-005.md L1127-1133) — The explicit do-not-preserve list dividing compatibility from accident.
- "The migration is not inventing governed professional execution from nothing. It is formalizing and generalizing mechanisms that already exist." (RPH-DOC-005.md L974) — Frames legacy strengths (roles, assumption surfacing, human gates) as assets being generalized, not replaced.

(RPH-DOC-005.md L1153-1164) — Confidence doctrine: explicit dispositions, residual uncertainty, and human decisions before any numeric score.

- "Every difference must be classified as: intentional semantic improvement; representation-only difference; missing legacy behavior; accidental legacy behavior; new implementation defect; unresolved design decision." (RPH-DOC-005.md L1657-1665) — Parallel-run adjudication taxonomy; no unclassified divergence allowed.
