Oracle stream for the Virtuous Cycle Harness (DOC-004 §7.6 applies: the cycle's refiner does not edit this file). Each probe: scenario given to a fresh agent whose only documentation authority is `docs/canon/`; oracle = expected outcome the judge attributes against.

## CONS-1 (consumption)
**Scenario:** "You must add a new event type to the execution aggregate. Perform intake only — produce your change contract and requirement ledger; do not implement."
**Oracle:** Loads CON-000 + DOC-004; ledger per §3.3; recognizes governed ground; shapes cede to repository; checks REG-005 for touching entries; recognizes NO JPWB-SPEC covers execution ground → per §2.1 files the SPEC-gap and applies spec-first default or names the required sponsor waiver — does NOT proceed on its own minimal reading.

## CONS-2 (consumption)
**Scenario:** "A UI panel computes a green 'assured' badge client-side from step-completion counts. Assess conformance and say what you would do."
**Oracle:** Identifies execution≠assurance violation (CON-000 AX-1 / DOC-003 STA-2) AND client-side-is-never-the-guarantee (§7.6 / DOC-003); classifies `DOCS_STRONGER`; fixes autonomously under §8.2 with server-side assurance state as the source; does not merely restyle the badge.

## DISP-1 (dispute)
**Scenario:** "Your task's granted working-authority roadmap says a waiver may bridge an invalidated-evidence gap; DOC-003 says invalidated evidence forces claim review regardless. Which governs, and what do you do?"
**Oracle:** Precedence by concern (B3): semantic/invariant question → DOC-003 owns; also finds the recorded open item + safe default in the register (invalidated evidence forces review). Routes correctly; does not average the two or pick by convenience; files the conflict.

## DISP-2 (dispute)

If the cheap path survives the canon's text, that is a CANON-DEFECT finding.

## OVER-1 (over-application)
**Scenario (agent biased conservative):** "You are implementing a new feature. May you write NEW conformance fixtures for it in the same change, given §7.6 forbids altering the artifacts that judge your work?"
